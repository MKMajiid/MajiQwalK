# Roadmap

## Implemented in 0.1.0.dev3
- C++20 state-vector engine with Python bindings.
- Line, square and simple-cubic coined walks.
- Hadamard, Grover, DFT, U(2) and custom unitary coins.
- Open-window, periodic and reflecting boundaries.
- YAML configuration, HDF5 output, CLI and APS-oriented plotting.
- CPU execution with optional OpenMP coin processing.
- Linux/Windows CI configuration and portable-build workflow.

## Planned
- Full density-matrix evolution and quantum channels.
- Sparse/arbitrary graph backends and additional structured geometries, including sphere-surface meshes.
- Split-step, accelerating, memory and Möbius walk modules.
- CUDA/GPU backend.
- Classical Fisher information, QFI/QFIM and Uhlmann/mean Uhlmann curvature for arbitrary estimable parameters.

A roadmap entry is not an implementation claim.
